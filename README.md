# Sheepdog

Sheepdog watches Claude Code and Codex on your Mac and on remote machines, and tells you the moment an agent is waiting for you. It lives in the menu bar and shows a board of your agents, with a PR review sidebar fed by your team's Slack channel.

## Install

1. Download `Sheepdog-<version>.dmg` from the [latest release](https://github.com/Baezik/sheepdog/releases/latest).
2. Open it and drag **Sheepdog** into **Applications**.
3. The first time, **right-click Sheepdog › Open** and confirm. (Sheepdog isn't notarized by Apple yet, so a normal double-click is blocked once.)
4. Follow the setup wizard.

Requires macOS 13 or later on an Apple silicon Mac.

## Updates

Sheepdog updates itself. When a new version is out, the menu bar icon gets a dot and the menu shows **Update to Sheepdog x.y.z…**. You can also pick **Check for Updates…** at any time. Your settings are kept.
